# 矿井瓦斯班测台

检查员上报测点甲烷浓度。达到 1% 时，服务端通过网页套接字把这条报警推到已经打开的页面，同时落一条推送审计：测点、浓度、推送时刻、当时在线套接字个数。审计是推送当时的快照，事后改正班测浓度不改写审计。顶栏「推送审计」可翻审计墙，也可按测点收窄；旁观账号只能看，不能上报。页面是手写脚本，没有用组件框架，也没有图表。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3191 |
| 接口 | http://localhost:8191 |
| PostgreSQL | localhost:54391 |

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| gasman | gas123456 | 可上报 |
| viewer | view123456 | 只能看 |

## 启动

```bash
cd projects/12-mine-methane-shift
docker compose up --build
```

## 验收

1. 用 gasman 登录，列表里回风巷是报警，东翼-12 是正常。
2. 开两个浏览器窗口都用 gasman 登录，上报一个 1.2，两个窗口都会出现新记录；顶栏「推送审计」里多一条，在线套接字个数至少为 2。
3. 在推送审计页按测点（如 回风巷）可收窄查询。
4. viewer 登录后没有上报表单，POST 上报返回 403，但可翻推送审计墙。
5. 事后改正该班测浓度，审计墙里那条的浓度仍是推送时的快照。
