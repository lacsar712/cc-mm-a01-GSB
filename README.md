# 矿井瓦斯班测台

检查员上报测点甲烷浓度。达到 1% 时，服务端通过网页套接字把这条报警推到已经打开的页面。页面是手写脚本，没有用组件框架，也没有图表。

每成功上报一笔达到报警线的班测，服务端除套接字推送外还会落一条**推送审计**（顶栏「推送审计」入口）：测点、当时浓度、推送时刻、当时在线套接字个数、上报人。审计是推送时刻的快照，事后改正班测浓度不会改写它；任何登录账号都能翻审计墙，并可用测点收窄查询，但只有检查员能上报。

## 端口

| 服务 | 地址 |

## 启动

```bash
cd projects/12-mine-methane-shift
docker compose up --build
```

## 验收

1. 用 gasman 登录，列表里回风巷是报警，东翼-12 是正常。
2. 再开一个浏览器窗口同时用 gasman 登录，两个窗口都停在班测页，上报一个测点浓度 1.2，两个窗口都会出现新记录。
3. 顶栏进入「推送审计」，审计墙新增一条：测点、浓度 1.2、推送时刻、在线套接字个数（两个窗口都开着时至少为 2）。
4. 在审计墙按测点输入名称查询，可收窄到该测点；WS 推送到达时审计墙也会实时刷出新行。
5. viewer 登录后没有上报表单，可以翻审计墙，直接调上报接口返回 403。
6. 事后在数据库改正该班测浓度，审计墙里的浓度仍是推送当时的 1.2。
